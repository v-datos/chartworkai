## Suitability screen

Keep completed responses in private owner-controlled storage.

1. What outcome does the project need to deliver, and over what expected period?
2. Does it already have a Git repository?
3. How many people, agent roles, or distinct workstreams contribute to it?
4. Which assistants or agent runtimes, if any, are currently used?
5. Which problems occur today: lost context, unclear authority, undocumented
   decisions, weak handoffs, or unreproducible output?
6. What would make this engagement successful after 14 days?
7. Which operating system and Python version will be used?
8. Can the participant install a Python package and commit repository changes?
9. Are there confidentiality, security, regulatory, or recording restrictions?
10. Who can approve the engagement and payment?
11. Is the participant available for one installation session and one follow-up?
12. Would the organization consider a separately reviewed named or anonymized case
    study? This answer is non-binding and does not affect eligibility.
