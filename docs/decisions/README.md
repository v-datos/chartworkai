# Decision Log

Dated, authority-stamped rulings for this project (the framework's own productization).

- **DEC-###** — scope / methodology / design decisions (files here).
- **FW-###** — framework issues and risks, tracked in `docs/data/watchlist.md`.

Each decision file: Date / Authority / Status header, Context (+ options), Ruling, Rationale, Implementation notes, Consequences per agent, Related decisions. Every non-README decision must be linked from `PROJECT_CHARTER.md` §8.
